# JavaDoc API Reference

The full JavaDoc for all hello-ebpf modules is published alongside these docs.

**[→ Open JavaDoc](https://parttimenerd.github.io/hello-ebpf/javadoc/)**

The JavaDoc covers the public API of:

- `me.bechberger.ebpf.bpf` — `BPFProgram`, `SchedulerBase`, `BPFJ`, map types
- `me.bechberger.ebpf.bpf.sched` — `DispatchQueue`, `CpuMask`, `EnqFlags`, `KickFlags`
- `me.bechberger.ebpf.annotations` — `@BPF`, `@BPFFunction`, `@Type`, `@InArena`, etc.
- `me.bechberger.ebpf.type` — `Ptr`, `Str`
